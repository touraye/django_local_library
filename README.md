# django_local_library
MDN Server-side programming using Django, Python

## Running The Development Server
* Clone the project.
* Make sure you have python installed and you have setup a virtual environment.
* Run this `workon` command to list your available virtual environment(s) if you have any.
* Pick a virtual environment to work with by running this command `workon name-of-your-virtual-environment`
* The name of your virtual environment will appear in front of your in the command prompt or terminal
* Navigate to where you clone the project, make sure you are sitting on the `locallibrary`directory.
* Run `py -3 manage.py runserver` if you are on Windows and `python3 manage.py runserver` for Linux/macOS.

Congrats if your ran your web-server successfully.
